ANLEITUNG

1. APK zum Ausprobieren
   GitHub > Actions > neuester Durchlauf > Artifact "AquariumPflege-apk" (enthält app-debug.apk).

2. AAB für Google Play erzeugen (einmalige Einrichtung)
   a) Schlüssel erzeugen (am PC, Java nötig):
      keytool -genkeypair -v -keystore upload.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000
      Passwörter notieren, Datei upload.jks SICHER aufbewahren (Backup!).
   b) Schlüssel in Text umwandeln:
      Linux/Mac: base64 -w0 upload.jks
      Windows (PowerShell): [Convert]::ToBase64String([IO.File]::ReadAllBytes("upload.jks"))
   c) GitHub > Repository > Settings > Secrets and variables > Actions > New repository secret:
      KEYSTORE_BASE64   = der Text aus b)
      KEYSTORE_PASSWORD = Keystore-Passwort
      KEY_ALIAS         = upload
      KEY_PASSWORD      = Key-Passwort
   d) Actions > "APK und AAB bauen" > Run workflow. Artifact "AquariumPflege-aab" enthält app-release.aab.

3. Google Play Console
   Entwicklerkonto anlegen (25 USD), neue App erstellen, Texte aus STORE-TEXTE.md und Bilder aus dem Ordner store/ verwenden,
   AAB unter "Test > Geschlossener Test" hochladen, Tester einladen. Bei neuen privaten Konten: 12 Tester, 14 Tage am Stück,
   danach Produktionszugriff beantragen.
